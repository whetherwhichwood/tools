# Tools

Public collection of **product management tools** and **case studies** from real product work — frameworks you can use, and shipped products you can learn from.

Maintained by [Griffin Baker](https://griffinbaker.com) · [whetherwhichwood](https://github.com/whetherwhichwood)

---

## Product tools

Curated, shareable PM skill libraries for Claude and AI-assisted product work. Each folder is a point-in-time snapshot of an upstream open-source project; see `UPSTREAM.md` in each project for source and refresh instructions.

| Project | What it is |
|---------|------------|
| [`projects/ai-pm-snapshot/`](projects/ai-pm-snapshot/) | AI PM Assistant — chained skills for PRDs, roadmaps, sprint planning, stakeholder updates, and more |
| [`projects/product-manager-skills-snapshot/`](projects/product-manager-skills-snapshot/) | PM skills framework for Claude Code and agent workflows |
| [`projects/pm-skills-snapshot/`](projects/pm-skills-snapshot/) | PM Skills Marketplace — discovery, analytics, execution, and strategy skills |

These are **tools**, not vanity repos: copy a snapshot into your own setup, adapt the skills, and cite upstream when you refresh.

## Using this repo

- **Browse tools** — start with any `projects/*-snapshot/README.md`
- **Read case studies** — [`CASE_STUDIES.md`](CASE_STUDIES.md) for context on each product
- **Contribute** — snapshots are refreshed periodically from upstream; open an issue if a snapshot is stale

Private experiments and configs are **not** in this repo.
