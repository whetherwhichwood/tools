# Recommended Free Tools

This stack already centers on OpenRouter, Codex, PM skills, GitHub, AXI tools, gnhf, worktrees, and Lavish. These free or free-tier tools complement that workflow without replacing it.

Pricing and limits change, so treat this as a starting checklist rather than a permanent procurement source.

## Start now

| Tool | Free use | Where it fits |
|---|---|---|
| [GitHub Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects) | Included with GitHub Free | Turns PM skill outputs into issues, status views, roadmaps, and release boards close to the code. |
| [NotebookLM](https://notebooklm.google/) | Free tier available | Source-grounded research workspace for PDFs, notes, strategy docs, and market research before running PM skills. |
| [Fathom](https://fathom.video/) or [Granola](https://www.granola.ai/) | Free individual/basic tiers available | Meeting capture and summaries that feed `meeting`, `triage`, `synthesis`, `prd`, and `case-study`. |
| [Amplitude](https://amplitude.com/) or [Mixpanel](https://mixpanel.com/) | Free product analytics tiers available | Event analytics for experiments, release checks, funnels, retention, and adoption metrics. Pick one first. |

## Add when useful

| Tool | Free use | Add when |
|---|---|---|
| [Dovetail](https://dovetail.com/) | Free tier available | You are running enough interviews or research projects that notes need a dedicated repository. |
| [Gamma](https://gamma.app/) | Free tier available | You want a quick deck, mini-site, or polished stakeholder artifact faster than building it manually. |

## Suggested workflow

1. Capture meetings and raw customer signal in Fathom or Granola.
2. Collect research sources in NotebookLM.
3. Run the relevant PM skill: `triage`, `discovery`, `prd`, `stories`, `risks`, `release-check`, or `case-study`.
4. Track execution in GitHub Projects.
5. Use Amplitude or Mixpanel once the product has real events.
6. Turn polished narratives into HTML with Lavish or decks/sites with Gamma when presentation matters.

## Avoid for now

- Paying for multiple analytics tools before there is real event volume.
- Paying for research repositories before there are recurring interviews.
- Adding another PRD generator before the PM skills have been tested across enough examples.
